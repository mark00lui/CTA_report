## 一、⚠ 本輪最重要的產出：一個新的失敗模式

本檔的 base 用的是**錨 C（reverse-DCF）**，而它曾讓本檔自「無獨立估值基礎」升級、
信心自低升至中。

**本輪用 state 自己記的數字做內部檢查**：

| | 隱含永續成長率（r=9%） |
|---|---|
| **市場**（市值 94.61B @ 345.88） | **+1.46%** |
| **本檔 base 15x** | **+1.4%** |
| 本檔 bear 10x | −2.0% |
| 本檔 bull 22x | +3.9% |

> ⚠ **base 的 +1.4% 與市場的 +1.46% 實質相同。**

而同一段 `multiple_basis` 的論證是：

> 「市場付的價格假設 INTU 的自由現金流**永遠只能跟上通膨甚至更慢**，
> 而公司 FY27 guidance 是營收 +9~10%、non-GAAP EPS +23~24%。
> 這個落差就是 AI 顛覆風險的定價。」

**也就是說：論證主張市場過度悲觀，然後 base 採用了市場的悲觀。**

### 這是一個新的失敗模式，值得命名

> **用 reverse-DCF「描述」市場假設，然後把那個假設當成自己的 base。
> 形式上是錨 C，實質上是 `valuation.md` 核心規則所禁止的「base = 現價隱含值」。**

它比原本的失敗模式更難察覺，因為：
- 它**有計算**（反推了三個折現率下的隱含成長）
- 它**有論證**（明確指出市場的假設不合理）
- 它**通過了原本的檢查**（`multiple_basis` 指向的不是「現價隱含倍數」而是「隱含成長率」）

**唯一能抓到它的方法，是把 base 的隱含值與市場的隱含值放在同一個尺度上比。**
本輪就是這樣抓到的，並已寫成可機械判定的 `changes_if`，每次重估都要重跑。

### 後果：信心還原

本檔的信心曾因取得錨 C 而自「低」升至「中」。
**既然那個升級的依據不成立，就該還原。信心降回「低」。**

## 二、⚠ 刻意不調整 base 的數字，而理由不是保守

要修正 base，就得指定一個「合理的永續成長率」來取代市場的 +1.46%。

**但折現率本身都還沒有可觀測錨。** r=8%／9%／10% 沒有依據——
而 `valuation.md` 已於 2026-08-31 **點名本檔為三個未錨定實例之一**，至今未補。

> **用一個未錨定的數字去修另一個未錨定的數字，不是修正。**

所以本輪的處置是：**標記問題、還原信心、把取得折現率錨定為最高優先的 `changes_if`**——
而不是動一個我沒有依據去動的數字。
