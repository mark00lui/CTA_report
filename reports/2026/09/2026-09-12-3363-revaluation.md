## 0. 先修正一件事：這一檔做得了

**佇列把本檔排在最後並註明「它兩條通道都不覆蓋，很可能仍做不了」。**

| 通道 | 結果 |
|---|---|
| 鉅亨 Factset 速報 | ⚠ **仍然是空的** —— 兩次不同關鍵字搜尋皆無 EPS 型亦無目標價型 |
| stockanalysis | ⚠ 上櫃 → 404（**本輪先以 wantgoo 確認了上櫃這個事實才跳過，沒有憑記憶**） |
| **wantgoo** | ✓ **可用** —— 價格、PE 欄位狀態、PB、季線、市值、上市／上櫃 |
| **鉅亨新聞（非速報）** | ✓ **可用，而且是本輪最有價值的一條** —— 自結的**月度**每股損益與月營收 |

✓ **所以「做不了」是高估了阻塞的範圍：Factset 的**共識**確實取不到，
但**公司自己公告的月度數據**取得到，而本檔的爭點剛好是月度層級的問題。**
⚠ **→ 「通道不覆蓋」要分成「共識取不到」與「一手數據取不到」兩件事。
前者對本檔成立，後者不成立。**

## 1. ⚠⚠⚠ thesis 的爭點有了第一筆數據，而判決一分為二

**thesis：「爭點是 8 月營收轉正來自 FAU 出貨還是跳線本業回溫」。**

### 營收側：支持 base

| | 值 |
|---|---|
| 2026 年 8 月營收 | **2.04 億元**（月增 **19.7%**、年增 **13.2%**） |
| → 7 月營收 | **1.704 億元** |
| 年化（8 月 × 12） | **24.5 億元** |
| TTM 營收（由資產週轉率 0.31 × 淨值 57.16 億反推） | **約 17.7 億元**（月均 1.48 億） |
| **base 的 FY2027 假設** | **28.0 億元** |

✓✓ **近月營收（1.70–2.04 億元）已比 TTM 月均高出約 20–38%，年化 24.5 億元 ——
而 base 的 FY2027 只需要再 +14%。**
**→ base 的營收假設本輪從「需要 FAU 出得來」變成「只需要目前的出貨水準再微幅成長」。
那是一個實質的強化。**
⚠ **法人並指出 9 月因 CPO FAU 出貨量持續提升，有望維持月增趨勢。**

### ⚠⚠⚠ 利潤率側：否證 base

**鉅亨載公司自結：**

| | 值 |
|---|---|
| **7 月單月稅後虧損** | **3,300 萬元** |
| **7 月單月每股淨損** | **0.29 元** |
| 7 月營收 | 1.704 億元 |
| **→ 7 月淨利率** | **−19.4%** |
| Q2 2026 單季每股淨損 | 0.22 元（＝ **每月 0.073**） |
| **7 月的月虧損率對 Q2 月均** | **3.97 倍** |
| **累計前 7 月每股淨損** | **1.47 元** |

⚠⚠⚠ **亦即：在法人所說的「FAU 出貨量持續提升」的同時，單月虧損擴大到 Q2 月均的四倍，
而 7 月的淨利率是 −19.4%。**

**而 base 的核心假設是什麼？state 自己寫得很清楚：**

> **毛利率假設：自 0.23% 改善到 20%** —— ⚠⚠⚠ 這是三情境裡最大的單一假設，
> 而我沒有任何 FAU 的毛利率數字。已立為新增的第五條 falsifier
> （2027 Q1 前合併毛利率任一季未達 10%）。

⚠⚠⚠ **現在有了第一個數字，而方向是反的。**
⚠ **要克制的地方**：7 月的 −19.4% 是**淨**利率不是毛利率，且放量初期的費用與折舊會壓低它 ——
**所以它不直接否證「毛利率 20%」，但它是這個問題上第一筆真實的證據，而它不利。**
**→ 第五條 falsifier 的觀察期應自「2027 Q1 前」提前到 **Q3 2026 財報**（約 2026-11），
因為 7 月已經給出了一個可以延伸的讀數。**

### ✓ 所以爭點的答案目前是：營收是真的，獲利還不是

**「8 月營收轉正來自 FAU 還是跳線本業回溫」這個二分法，本輪可以部分回答：**
**不論來自哪一邊，它目前都沒有帶來獲利 —— 而那比「來自哪一邊」更要緊。**

## 2. ⚠⚠⚠ 而本檔的模型沒有一個欄位會對上面那個發現起反應

**本檔三情境的 `exit_multiple` 記的是**市營比**，不是本益比 ——
因為 TTM EPS 為 −1.18，本益比不存在。`eps` 三格都是 `__`。**

✓ **那個處置是對的**（valuation-map Q3 的處方，而 state 已經照做）。
⚠⚠⚠ **但它的代價本輪第一次具體化了：市營比完全忽略利潤率，
所以「7 月淨利率 −19.4%」這個本輪最重要的新事實，在模型裡沒有任何一格會動。**

**state 自己在 bear 就寫過這一點：**

> ⚠⚠ **而市營比完全忽略毛利率 —— 本情境的毛利率假設是約 0%，
> 那一格因此是三情境裡唯一沒有改善假設的。**

⚠⚠ **亦即：三個情境的毛利率假設分別是約 0%／20%／25%，
而三個目標價完全由「FY2027 營收 × 市營比」決定 —— 毛利率假設在算式裡不出現。**
**→ 本檔的目標價對它自己宣稱的最大單一假設是**不敏感**的。**

### 那該怎麼辦？本輪不動數字，但把它立成缺口

⚠ **不改成本益比**：EPS 仍為負，本益比算不出來。
⚠ **不自己加一個毛利率修正項**：那需要一個我沒有的 FAU 毛利率數字，加了就是編造。
✓ **能做的是把這個結構限制寫成明文，並指定它的解法**：
**當任一季合併毛利率揭露後，本檔應自市營比改為 EV/Gross Profit 或市營比 × 毛利率，
讓毛利率進入算式。已列為首要缺口。**

⚠⚠ **這也解釋了一件事：為什麼營收側的強化（年化 24.5 億、只需再 +14%）
沒有讓目標價變好。因為營收已經在算式裡，而它的改善被 base 的 28.0 億假設吸收掉了；
真正變壞的那一半（利潤率）不在算式裡。**

（「FY2027 營收 20.0／28.0／40.0 億元」）—— 內容有基準年而結構沒有。**

## 4. §9b 的四項檢查 —— 其中兩項在本檔無法執行，而原因本身是發現

### ✓ (a) 循環性：乾淨，而且本輪要肯定一條規則擋下了什麼

**base 的 20.48 ＝ 同業中位數（波若威 3163 的 27.02／前鼎 4908 的 20.48／聯鈞 3450 的 7.40），
而 state 明確檢查過它不是現價隱含值。以新價重算：**

| | 值 |
|---|---|
| 現價 681 × 股數 1.1363 億 ＝ 市值 | **773.8 億** |
| ÷ base 的 FY2027 營收 28.0 億 ＝ 現價隱含市營比 | **27.64x** |
| base 取 | **20.48x** |
| **折價** | **−25.9%**（state 以 714 計記 −29.3%） |

✓ **折價仍然實質存在，結論方向不變。**

⚠⚠ **而 state 記了一件值得單獨肯定的事**：

> ⚠⚠⚠ **我一開始把 base 設成同業最高的 27.02，那會使 base 只比現價隱含值低 6.8%、
> 加權只有 −3.8%（落在 ±5% 內）。是「用中位數不用平均」這條規則把它擋回來的 ——
> 規則的價值應該被記成「它擋下了什麼」，不只是「它說了什麼」。**

✓✓ **那是整個二十四檔裡唯一一次明確記下「某條規則擋下了一個具體的錯誤結論」。
本輪確認它仍然成立：若 base 取 27.02，目標價為 666（相對 681 為 −2.2%），
而取中位數 20.48 是 505（−25.9%）—— 一個落在雜訊內、一個是明確的方向判斷。**

⚠ **但有一個年度錯配要記**：三個同業市營比**未標年度**，推定為 trailing
（現市值 ÷ 現營收），而它們被乘的是 **FY2027** 的營收。
**這是 6531／3131／3533／3665／2317 那個錯配的第六個實例，而且是市營比版本。**

### ⚠⚠⚠ (b) 恆等式無法執行 —— 而原因是本益比不存在

**`市營比 ＝ 本益比 × 淨利率` 這個恆等式（3661 那輪建立，之後八檔皆通過）
**在本檔無法執行**：本益比不存在（TTM EPS −1.18，wantgoo 的 PE 欄位顯示「--」）。**

⚠⚠ **這是第一次有檢查因為「盈餘為負」而整個不適用。**
**→ 回填：該恆等式的前提是盈餘為正。對虧損標的，它不是通過也不是失敗，是不適用；
而那正好標示出「這一檔的估值不能走盈餘軸」。**

✓ **能算的是「哪一年」的幅度**：市營比以 TTM 營收 17.7 億計為 **43.7x**、
以 8 月年化的 24.5 億計為 **31.6x**、以 FY2027 的 28.0 億計為 **27.64x**。
**TTM 對 FY2027 ＝ 1.58 倍。**

### ⚠ (c) 無法執行兩次

**(i) 沒有任何共識**（Factset 通道空、無分析師覆蓋）→ 沒有中位數可比。
**(ii) 三個情境的 `eps` 都是 `__`** → 連一個「bull 的 EPS」都不存在。
**→ §9b(c) 在本檔是雙重不適用，而不是未通過。**

### ⚠ (d) 全距 4.51 倍，而「EPS 段」在本檔是營收段

| | 倍數 |
|---|---|
| 全距 951 ÷ 211 | **4.51×** |
| **營收段** 40.0 ÷ 20.0 | **2.00×** |
| 市營比段 27.02 ÷ 12 | **2.25×** |
| **市營比段佔對數全距** | **53.9%** |

⚠ **這是二十四檔裡第一次「EPS 段」其實是營收段 —— 因為整個模型是營收驅動的。**
**兩段大致均衡（53.9%／46.1%），對照 3030 的 84.1% 與 6187 的 26.8%。**

| | 值 | 相對現價 681 |
|---|---|---|
| 算術加權 | **543** | **−20.3%** |
| 幾何加權 | **476** | **−30.1%** |
| 兩者差 | **14.1%** | |

**兩者同號（皆為負），方向性判斷穩健。**
⚠ **14.1% 是二十四檔裡同號者中最大的算術／幾何差**（前一個最大是 3661 的 10.7%）——
**成因是全距 4.51 倍在同號的標的裡也是最寬的。**

⚠⚠ **而兩者皆為負這件事要說清楚**：**本模型認為現價高於它的加權目標價 20.3%，
而幾何加權更低 30.1%。這是 3324 之後第二檔出現負上檔空間的標的。**

  → 淨利率 −19.4%；累計前 7 月每股淨損 1.47 元；7 月月虧損率為 Q2 月均的 3.97 倍**

1. ⚠⚠⚠ **模型的市營比結構無法表達本輪最重要的發現。**
   三情境的毛利率假設（約 0%／20%／25%）在目標價算式裡完全不出現，

   而 base 自己宣稱毛利率是它最大的單一假設。**

   讓毛利率進入算式。**
2. ⚠⚠⚠ **第五條 falsifier 的觀察期應自「2027 Q1 前」提前到 Q3 2026 財報（約 2026-11）** ——
   7 月已給出一個可延伸的讀數（淨利率 −19.4%），不必再等四個季度。

## 7. 回填 references 的新增項

1. ⚠⚠⚠ **「通道不覆蓋」要分成「共識取不到」與「一手數據取不到」兩件事，它們的後果完全不同。**
   **本檔實測：Factset 共識確實兩次搜尋皆空（與 3030、6442 同為完全未覆蓋型），
   但 wantgoo 給出價格／PB／季線／市值／上市櫃，鉅亨新聞給出**自結的月度每股損益**——
   而本檔的爭點剛好是月度層級的問題，所以一手數據比共識更有用。**
   **→ 佇列裡標註「做不了」的標的，要先分清楚缺的是哪一種。**
2. ⚠⚠⚠ **當模型的驅動量是營收（市營比）時，它對利潤率假設是結構性不敏感的 ——
   而那個假設往往是 thesis 的核心。**
   **本檔實測：三情境的毛利率假設分別是約 0%／20%／25%，
   而目標價完全由「FY2027 營收 × 市營比」決定；
   7 月淨利率 −19.4% 這個最重要的新事實在模型裡沒有任何一格會動。**
   **→ 用市營比時必須明寫「本模型對毛利率不敏感」，並指定一個讓毛利率進入算式的升級路徑
   （EV/Gross Profit，或市營比 × 毛利率）。**
3. ⚠⚠⚠ **恆等式 `市營比 ＝ 本益比 × 淨利率` 的前提是盈餘為正。**
   **本檔實測：TTM EPS −1.18，本益比不存在（wantgoo 的 PE 欄位顯示「--」），
   該檢查整個不適用 —— 不是通過也不是失敗。
   而「它不適用」本身就標示出這一檔的估值不能走盈餘軸。**
   **→ 這是該恆等式建立（3661）以來第一次不適用，前八檔皆通過。**
4. ⚠⚠ **基準年可以掛在營收而不是 EPS 上，而那必須在欄位旁註明。**
   **本檔實測：`valuation_base_year: 2027` 指的是 FY2027 的**營收**（20.0／28.0／40.0 億元），
   因為 EPS 為負；若不註明，下一輪會去找「FY2027 的 EPS 共識」，而那不存在也不相關。
   二十四檔裡只有本檔是這一類。**
5. ⚠⚠⚠ **規則的價值要被記成「它擋下了什麼」，而本檔是二十四檔裡唯一一個明確記下來的。**
   **state 原記：把 base 設成同業最高的 27.02 會使加權只有 −3.8%（落在 ±5% 內），
   是「用中位數不用平均」把它擋回來的。本輪以新價確認：27.02 → 目標價 666（−2.2%，雜訊內）；
   20.48 → 505（−25.9%，明確的方向判斷）。**
   **→ 這種記法應該推廣：每條規則在某一檔擋下了什麼，寫在那一檔裡。**
6. ⚠⚠ **「≥2 個日振幅」的第三個實例，而本檔最直接：同一條均線、同一個價格，
   比值在 1.24（以 7.74% 計）與 2.08（以 4.62% 計）之間跨過門檻。**
   **→ 2317 是門檻太鬆、6442 是太嚴、本檔是「分母的取法直接決定結論」。
   ATR 因此不是精度問題而是判定問題。**
7. ⚠ **公司自結的月度損益是一個被低估的通道。**
   **本檔實測：它給出了 7 月單月每股淨損 0.29 元與累計前 7 月 1.47 元 ——
   而那是共識、財報季報都給不了的頻率，且正好落在爭點的時間尺度上。
   → 抓一手數據時，除了月營收，也要搜「自結」。**
