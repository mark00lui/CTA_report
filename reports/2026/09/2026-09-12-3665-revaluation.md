# 3665 全量重估 —— 同樣是整座階梯低於共識，但這一次沒有理由

## 1. §9b(c) 連續第二次失敗

| | state | FY2027 共識 | 差 |
|---|---|---|---|
| bear 50.0 | | 低 **85.31** | **−41.4%** |
| **base 80.0** | | 低 **85.31** | **−6.2%** ⚠ **低於共識下緣** |
| | | 中位 **111.23** | −28.1% |
| **bull 100.0** | | **中位 111.23** | **−10.1%** ⚠⚠⚠ |
| | | 高 127.09 | −21.3% |

**前一檔 3533 是 −18.8%，本檔 −10.1% —— 連續兩檔，而兩檔的同業還重疊
（TEL／立訊／信邦／APH 是同一組）。**

### §9b⑦ 的量化：落後約 0.7 年

**共識 FY2026 中位 64.80 → FY2027 中位 111.23。
base 的 80.0 落在 (80.0 − 64.80) ÷ (111.23 − 64.80) ＝ **32.7%** 的位置。**
**→ 模型的 FY2027 base 約等於街上眼中的 2027 年初，落後約 0.7 年。**
⚠ **比 3533 的 1.2 年輕微，但方向相同。**

## 2. ⚠⚠⚠ 而本檔的落差 100% 在成長率，且被自己的營收數據反駁

**base 的推導是「FY2026E 約 64 再成長 25%」。**

| | state | 共識 | 差 |
|---|---|---|---|
| FY2026 基期 | **約 64** | **64.80** | **−1.2%** ✓ |
| FY26→27 EPS 成長 | **+25%** | **+71.7%** | **−46.7pp** |
| FY2027 | 80.0 | 111.23 | −28.1% |

✓ **基期幾乎完全一致 —— 所以落差 100% 來自成長率的判斷，沒有任何一部分來自算錯或口徑。**
**（與 3017 同型的乾淨歸因。）**

### ⚠⚠⚠ 但那個成長率與本檔自己記下來的營收數字相矛盾

**state 自己的 `key_variables` 與 base 的推導裡寫著：**

| 已實現 | 值 |
|---|---|
| 營收年增 | **+40.01%** |
| Q3 前兩月月均 92.61 億元 對 Q2 月均 77.51 億元 | **+19.5%（季對季，仍在加速）** |
| HPC 佔比 | 1Q25 **27%** → 1Q26 **45%** |

**而 base 假設 FY2027 EPS 成長 +25%。在利潤率持平的假設下（base 自己用的就是
「套用 Q2 推算淨利率 13.11%」），+25% 的 EPS 成長隱含約 +25% 的營收成長 ——
比本檔已實現的年增率低 **15 個百分點**。**

⚠⚠ **對照共識：FY2026 營收 962.63 億 → FY2027 中位 1,309.91 億 ＝ **+36.1%**，
那還低於已實現的 +40.01%。**
**→ 亦即共識的營收假設已經是減速的，而 base 的假設比共識再減速一大截，
卻沒有給出任何理由。**

### 對照 3533：同樣是低於共識，理由的有無決定處置

| | 3533 嘉澤 | **3665 貿聯** |
|---|---|---|
| 低於共識的機制 | **管理層自己說**：原料佔 COGS 自 45–50% 升到 65%；Q1 的 49.55% 毛利率是低價庫存的產物 | ⚠ **無** |
| 實績印證 | ✓ 單季淨利率 Q1 25.61% → Q2 20.86%，掉 4.75pp 而營收幾乎沒動 | ⚠ **反向**：營收年增 +40.01%，Q3 仍在加速 |
| 處置 | **base 不換成共識中位** | **base 換成共識中位** |

⚠⚠⚠ **這一組對照本身就是本輪最有價值的產出：
「整座階梯低於共識」不是一個可以統一處理的現象 ——
要先問「低的那個理由是什麼，以及它有沒有被自己的數據支持」。**

## 3. bear 的 50.0 也不成立，而它的問題是另一種

**bear 的 `key_assumption` 自己寫著：**

> ⚠ 後者是本檔獨有的風險：那 55%（電動車／工業／醫療／電器）的內部組成與各自毛利率
> **全部未取得，故無法估計它轉弱的幅度**。

**而 50.0 隱含的 FY2027 淨利率：**

| 以哪個營收計 | 隱含淨利率 |
|---|---|
| FY2027 共識**低** 1,091.62 億 | **8.94%** |
| FY2027 共識中位 1,309.91 億 | **7.45%** |
| *對照：* **Q2 2026 實績** | ***13.11%*** |
| *對照：* TTM | *12.87%* |
| *對照：* FY2026 共識隱含 | *13.13%* |

⚠⚠⚠ **50.0 要求淨利率掉到觀測區間之下 4.2–5.7 個百分點，
而它的機制是一個 state 自己承認無法量化的東西。**
**一個自承無法估計幅度的機制，不該定出一個具體且極端的數字 —— 那是把「不知道」寫成了「很糟」。**

### 改用一個全程可驗算的構造

```
Q2 2026 淨利率 13.11%  ×  FY2027 共識營收【最低】 1,091.62 億元
  ＝ 淨利 143.11 億元  ÷  股數 1.9508 億股
  ＝ FY2027 EPS  73.36
```

**採 73.40。這一格的意思是：「營收落在最悲觀分析師的位置，而且利潤率完全沒有回升。」**

⚠⚠ **它比共識 EPS 最低的 85.31 低 14.0% —— 所以它仍然是一個真正的 bear，
沒有退化成共識的複製。**
**差額的來源很清楚：共識的 EPS 下緣配的是「低營收 ＋ 一部分利潤率回升」，
而本情境把利潤率回升那一段拿掉。**

⚠⚠⚠ **而它恰好也保住了 state 原本想表達的風險**：
**FY2026 營收 962.63 億 → FY2027 共識最低 1,091.62 億 ＝ **+13.4%**，
對照已實現的 +40.01% 是一次劇烈的減速 —— 那正是「非 AI 那 55% 的循環同時轉弱」的形狀，
而且是由看得見分部拆分的分析師定出來的幅度，不是由看不見的人猜的。**

## 5. §9b 其餘檢查

### ⚠⚠ (a) 循環性 —— 三個倍數裡有兩個是價格的函數

| 情境 | 倍數 | 依據 | 是否獨立於現價 |
|---|---|---|---|
| bear | **20** | TEL 的 20.03（清單外同業） | ✓ **獨立** |
| base | **28** | 同業中位數 23.92 **＋ 保留一部分「本檔目前的溢價」** | ⚠ **部分依賴** |
| bull | **35** | 「接近**本檔目前水準**（35.34）」 | ⚠⚠ **完全依賴** |

**base 的原文**：

> 給 28 倍的理由：成長溢價保留約一半 —— 自目前的 **+47.7%（對中位數）** 收斂到 +17.1%。

⚠⚠ **那個 +47.7% ＝ 本檔 trailing PE 35.34 ÷ 同業中位 23.92 − 1 ——
它是**現價**除以 TTM EPS 得來的。所以 28 這個數字會隨現價移動：
現價跌 20%，trailing PE 變 28.27，溢價變 +18.2%，同樣保留 35.8% 後倍數變 25.5。**

⚠ **而且「保留約一半」與執行的數字不符**：
**+17.1% ÷ +47.7% ＝ **35.8%**，保留的是約三分之一不是一半。
若真的保留一半（+23.9%），倍數應為 **29.63**，base 目標價為 3,296（+5.8%）。**

**→ 三個倍數本輪全部維持不動**（改它們需要同業的 **FY2027** forward PE，
現有四家全是 trailing，依 6531／3131 先例不可用），**但把上表列出來，
讓「有兩格是現價的函數」是一件被寫下來的事。已列缺口。**

⚠ **這是 3017／3583 那個問題的第三種濃度**：
3017／3583 是三格全部派生自本檔 trailing PE；本檔是一格獨立、一格部分、一格完全。

**§9b⑭：檢查跑了、兩處一致 —— 記下來。**

⚠ **「哪一年」的幅度**：市營比 TTM **4.44x** 對 FY2027 共識 **2.79x**，差 **1.59 倍** ——
與 3017 的 1.64 倍相近，遠小於 3661 的 4.21 倍。

## 6. ⚠⚠⚠ 價格：四個值，而這一次它反轉了一個技術判定

| 來源 | 值 | 日期 |
|---|---|---|
| `cta.price` | **1,975.00** | 2026-09-09（由 key_ma 的季線與距離反推：2,077.54 − 102.54） |
| `methods.primary`「昨收」 | **1,935** | ⚠ 與下一列同日但差 0.26% |
| `cta` 六條均線註解 | **1,930.00** | 2026-09-10 收盤 |
| `base.multiple_basis` | **1,930** | 2026-09-10 |
| **stockanalysis** | **1,875.00** | **2026-09-11 13:30，當日 −2.85%** |

⚠⚠ **`cta.price` 比實際收盤高 **5.33%** —— 本系列最大的價格誤差**
（前高為 3661 的 6.99%… 不，3661 是 3,905 對 3,650 ＝ 6.99%；本檔 5.33% 為第二大）。
**成因是連續三個交易日下跌：1,975 → 1,930 → 1,875（兩個交易日 −5.06%），
而權威欄位停在第一天。**

### ⚠⚠⚠ 而這一次它會反轉一個判定 —— 3131 之後第二次

**`cta.key_ma` 寫著：**

> 季線約 **2,077.54 元**，季線距現價 ＝ **+5.19%**。
> ⚠⚠ **而本檔提供了「必須用比值不能用絕對百分比」最乾淨的一次證明**：
> 3211 順達的季線距現價也是 +5.19% —— 完全相同的絕對距離。
> 但 3211 的日振幅是 4.39%（比值 1.18 倍，判為偏緊），
> **本檔的日振幅是 6.46%（比值 0.80 倍，判為太近）。**

**以實際收盤 1,875 重算：季線 2,077.54 ÷ 1,875 − 1 ＝ **+10.80%** ——
距離是原記的 2.08 倍。**

| 日振幅用哪一個 | 比值 | 判定 |
|---|---|---|
| 6.46%（09-09 讀數，state 用的） | **1.67 倍** | ⚠ **不再是「太近」** |
| 2.53%（09-10 讀數，均線註解所載） | 4.27 倍 | 遠 |

⚠⚠⚠ **原本「太近，不可用」的判定，在正確的價格下不成立。**
**而那個判定還被寫成了「必須用比值不能用絕對百分比」的示範案例 ——

## 9. 回填 references 的新增項

1. ⚠⚠⚠ **「整座階梯低於共識」不是一個可以統一處理的現象。**
   **要先問兩題：(i) 低的理由是什麼？(ii) 那個理由有沒有被本檔自己的數據支持？**
   **3533：理由是管理層自己說的原料成本結構，且被單季淨利率 25.61% → 20.86% 印證 → base 不換。**
   **3665：沒有理由，而且營收年增 +40.01%、Q3 仍在加速，正好反著走 → base 換成共識中位。**
   **兩檔同日、同一組同業、同一個徵狀，處置相反 —— 判準是證據不是徵狀。**
2. ⚠⚠⚠ **「自承無法量化的機制」不該產生一個具體且極端的數字。**
   **本檔實測：bear 的 key_assumption 自己寫「全部未取得，故無法估計它轉弱的幅度」，
   而 50.0 隱含淨利率 7.45–8.94%，比近兩年觀測到的 12.87–13.76% 低 4.2–5.7 個百分點。
   那是把「不知道」寫成了「很糟」。**
   **→ 替代作法：用共識分布裡已經反映該風險的那一格（本檔是營收下緣 +13.4%，
   對照已實現的 +40.01%），再疊上自己真正有把握的那一段（利潤率不回升）。
   結果 73.36 仍比共識 EPS 下緣低 14.0%，所以它沒有退化成共識的複製。**
3. ⚠⚠ **「Q2（最近一個乾淨季度）的利潤率 × 共識營收」這個構造，兩檔都落在共識 EPS 下緣附近**
   （3533：91.54 對 85.31… 對 92.20，差 0.72%；本檔：88.03 對 85.31，差 3.2%）。
   **→ 它是一個可重複的構造，而它的意義是「共識下緣 ≈ 利潤率不回升」。
   下一檔起直接當標準動作做。**
4. ⚠⚠⚠ **價格過期會反轉技術判定，而且不只一次（3131、本檔）。**
   **本檔實測：季線距現價自 +5.19% 變 +10.80%（2.08 倍），
   使「太近不可用」的判定不成立 —— 而該判定還被寫成了一個方法論的示範案例。**
   **→ 凡是被引用為「示範案例」的數字，比一般數字更需要重新驗證，
   因為它會被別的檔案引用而擴散。**
5. ⚠⚠ **「保留約一半」這類自然語言的規則會與算式脫鉤。**
   **本檔實測：文字寫「保留約一半」，算式執行的是 35.8%。
   → 規則要寫成數字，或者把算式完整寫出來讓它自我檢查。**
6. ⚠ **7 檔裡有 4 檔的「52 週振幅 ÷ beta」在 5.0 以上 —— 這已是常態不是例外。**
   **→ 應自個股註記升格為覆蓋層的共同前提：
   5 年期 beta 對台股 AI 供應鏈整體不可用於折現率。留給收尾報告。**
