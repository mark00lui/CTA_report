## 第一部分：重錨結果

### 為什麼重錨

2026-08-27 一天內完成十一檔首次估值，事後檢查發現**八檔的 base 目標價落在現價 ±4% 以內**，原因是每份報告都把 base exit multiple 設成現價隱含值，並寫上「刻意不靠重評價支撐目標價」。那句話讀起來像紀律，實際上是放棄判斷——base 權重 0.5，base ≈ 現價就讓加權目標價機械性地貼著現價。

規則已寫成 `references/valuation.md`。本次是它的全清單適用。

### 這次差點犯的第二個錯

修正「base ＝ 現價」之後，最順手的下一步是**把 base 直接換成歷史平均**。若那樣做：

| ticker | 現況 vs 歷史 | 機械套用歷史平均的話 |
|---|---|---|
| NVDA | -32% | base 34.2x → 加權約 285 |
| META | -25% | base 22x → 加權約 694 |
| INTU | -56% | base 39x（新口徑）→ 目標價近 900 |
| MSFT | -8% | 小幅上修 |
| GOOG | +15% | 下修 |
| TSM | +38%（trailing） | 大幅下修 |
| MU | +30%（trailing） | 大幅下修 |

**八檔美股裡五檔會大幅上修。「什麼都沒錯價」會一夕變成「什麼都便宜」——那不是修正，是換一種偏誤。**

關鍵認知：**現價偏離歷史區間，通常是因為市場相信有東西變了。** 歷史倍數只在「那個變化是暫時的」成立時才是有效的 base 錨。所以歷史區間必須分兩步用——定位（事實）、判斷（估值）——而第二步才是估值。這條已補進 `valuation.md`。

本次三種判斷結果都出現了，且都寫進 `multiple_basis`：

- **不合理**（GOOG）：折舊尚未入帳就付溢價，只算了一邊
- **部分合理**（NVDA、META、MSFT）：折價有真實理由但幅度過度，只修復一半
- **完全合理**（TSM）：毛利率自 50% 出頭升至 67.7%，結構性改善支撐 17% 溢價

第三種與「base ＝ 現價」的差別**不在數字，在於有沒有做過那個判斷**。TSM 的 19x 前後沒動，但它現在有理由——下次毛利率變化時，我知道該不該動它。

### 同時發現的口徑陷阱

查歷史錨時發現：**十一檔裡只有 NVDA 與 INTU 拿得到乾淨的歷史「遠期」本益比**，其餘查到的都是 **trailing**。而三情境的分母是次年預估 EPS，是 forward。

成長中的公司 forward EPS 高於 trailing → forward 倍數必然低於 trailing 倍數。拿 trailing 歷史平均直接當 forward 的 base，**公司成長越快、錯得越多**。本次全部經 `forward ≈ trailing ÷ (1+g)` 換算並在 `multiple_basis` 寫明成長率。這條規則原本 `valuation.md` 漏了，已補上。

副產品：發現 MSFT 的 bull 倍數 31x 口徑存疑（原依據「近五年區間 25–35x」未確認 trailing/forward；若為 trailing，31x forward 對應 trailing 約 36.6x 反而高於區間上緣，bull 比表面上更激進）。已列入該檔 gaps，未擅自更動數值。

### 信心度下修一檔

**INTU 自「中」下修至「低」。** 其歷史 forward 5 年平均 31.22x 雙重失效：(1) 該期間跨越 AI 顛覆疑慮發生前後；(2) FY2026 起 non-GAAP EPS 納入 SBC，口徑改變（歷史換算為新口徑約 39x，與現況 13.7x 差距 65%——而那個差距的合理性正是本檔的核心未知，不能反過來當錨）。

依 `valuation.md`，無獨立估值基礎者 `signal.conviction` 上限為低。**這不是對基本面看法轉差，是承認估值判斷缺乏依據。** 清單中信心度為「低」者現為五檔：INTU、MU、SNDK、6442、3008。

## 第二部分：與市場分析的差異化評估

### 主要發現：街上目標價系統性落在本模型的 bull 情境

**八檔有街上對照的標的中，七檔的街上目標價落在本模型的 base 與 bull 之間（平均偏 bull 約 62%），NVDA 甚至高於本模型的 bull。**

### 這個差距有多少是結構性的？

**先扣掉不算數的部分。** 街上目標價是**點估計**（「順利的話值多少」），本模型是**機率加權**（含 0.25 的 bear 權重）。拿加權比點估計，本來就會系統性偏低。這不是意見不同，是計算方式不同。

正確的比法是 **base 對街上**：

| ticker | 本模型 base | 街上 | base vs 街上 |
|---|---|---|---|
| NVDA | 260 | 306 | -15% |
| GOOG | 297 | 422 | -30% |
| META | 659 | 755 | -13% |
| TSM | 418 | 554 | -25% |
| MU | 1,008 | 1,515 | -33% |
| SNDK | 1,499 | 2,126 | -29% |
| 3324 | 1,261 | 1,425 | -12% |

**即使 base 對街上，本模型仍系統性低於街上 12–33%。所以不只是結構。**

### 分歧在倍數，不在 EPS

本模型的 base EPS **多數直接採用市場共識**（TSM 22.00、GOOG 13.5、META 34.70、MU 155.03、SNDK 214.1、3324 57.34 皆為共識或由共識推導）。分母相同，差距就全在分子的倍數上。

**這是一個可以明確陳述的分歧：對同樣的獲利預估，街上願意付的倍數比本模型高 12–33%。**

三個可辨識的來源：

1. **記憶體兩檔差距最大（MU -33%、SNDK -29%）——這是框架分歧而非預估分歧。** 街上把峰值 EPS 配上較高倍數；本模型依 `valuation.md` 的循環股規則，採「峰值 EPS × 低倍數」並**強制並列正常化對照**。反推出來的數字值得記下來：
   - MU：現價 974 ÷ trailing 中位 16.78x ⇒ 市場隱含的中週期正常化 EPS 約 **58 美元**，為 FY2027 峰值共識 155.03 的 **37%**
   - SNDK：現價 1,555 ÷ 約 16.8x ⇒ 隱含中週期 EPS 約 **93 元**，為峰值共識 214.1 的 **43%**
   
   **SNDK 的比例高於 MU**——市場對這檔 2025-02 才分拆、沒有獨立循環紀錄的公司，反而假設更高的獲利可持續性。這個相對關係值得存疑，也是可驗證的：下一輪循環谷底來時對照即知。

2. **平台端（GOOG -30%）差距次大**，來源是 capex 折舊的時點。本模型認為 $205B capex 的折舊尚未入帳，此時給溢價等於只算 Cloud 的好處不算成本；街上顯然不這樣算，或認為 Cloud 的爬升速度足以吸收。**這是可驗證的分歧**：Q3/Q4 財報的營益率就是答案。

3. **3324 差距最小（-9.5%）——但那是方法造成的，不是共識。** 該檔是清單中唯一 base 錨在賣方目標價隱含值（24.9x 打折至 22x）的一檔。錨在街上，自然貼近街上。取得自身歷史分位後應改錨，已列入 gaps。

### 唯一反向的一檔，以及它為什麼不算

**3008 是唯一本模型高於街上的（+25.5%），但這不是「我比街上樂觀」——是街上的數字過期。**

街上目標價 5,220 停在 **2026-07-27**，早於其後的兩根漲停，現價 6,915 已高出該目標價 32.5%。`valuation.md` 把「用過期的賣方目標價當保守參照」列為已知的自欺模式；此處方向相反（用過期目標價讓自己顯得樂觀）但同源。

**因此本檔不應計入差異化統計。** 扣掉它之後，本模型對街上是**七戰全負**——沒有任何一檔比街上樂觀。

### 單向的分歧要當成警訊，不是洞見

七檔全部同方向偏低，這件事本身需要解釋。**單向的分歧通常是方法造成的，不是洞見。**

**支持「這是真實觀點」的證據：**
- 賣方評等分布有已知的樂觀偏誤——NVDA 為 Strong Buy 49／Buy 9／Hold 2／**Sell 0**
- 街上目標價的上升有時來自倍數擴張而非獲利上修。3324 的 FactSet 兩次調查是實例：EPS 58.08 **→ 57.34（下修）**，目標價 1,320 **→ 1,425（上修）**，隱含倍數由 22.7x 升至 24.9x。目標價共識對「市場願意付幾倍」的依賴高於對「公司賺多少」的依賴，而前者比後者脆弱
- 本模型的倍數有寫明的錨；街上目標價的錨未揭露

**支持「這是我的偏誤」的證據——這幾條同樣要寫出來：**
- **七檔全部同方向，沒有一檔例外。** 若是逐檔獨立判斷的結果，不該如此整齊
- **bear 權重 0.25 且多數 bear 錨是推論值**（GOOG 20x、META 13x、3324 15x、6442 26x 皆未取得歷史低分位）。推論出來的 bear 若設得太低，加權就會系統性偏低
- **「部分合理」的判斷一律取中間值**（NVDA 折價修一半、META 折價修一半）。取中間是一種預設，不是分析。真正的分析該說明為何是一半而不是三分之一或三分之二——本次沒有做到這一點
- 十一檔中五檔信心度為「低」、四檔完全沒有獨立估值基礎。**在這種資料狀態下宣稱系統性看到街上看不到的東西，證據不足**

**結論：這個 -12% 到 -33% 的差距，目前應視為「待驗證的分歧」而非「已發現的錯價」。** 驗證方式是等時間——Q3/Q4 財報會告訴我們，是街上的倍數太高，還是我的 bear 錨太低。

## 第三部分：撤回 2026-W35 週報的循環結論

該週報寫著：

> **八檔全部完成建模後，估值全距只有 −0.5% 到 +19.3%，沒有一檔出現大幅低估。**
> 推論是：**這份清單目前沒有明顯的定價錯誤。**

**這個結論是循環論證，本報告予以撤回。**

當時八檔的 base 倍數全部錨在現價隱含值。base 權重 0.5，加權目標價因此必然貼近現價。**那不是對市場的發現，是把八個「我沒有意見」加總後誤讀成「市場沒有錯價」。**

重錨後的實際分布是 **-5.6% 到 +19.4%**，全距沒有大幅擴張——但**意義完全不同**：現在其中三檔（NVDA、GOOG、META）的 base 有明確的獨立錨，它們的位置是算出來的結論；另外幾檔仍無獨立錨，它們的位置**依然不構成對市場效率的任何陳述**。

`valuation.md` 已寫入衍生規則：多檔 base 都落在現價 ±5% 內時，**不得在覆蓋層聚合成「清單沒有明顯定價錯誤」這類結論**，除非先確認多數檔的 base 有獨立錨。

該週報的其他內容（因子集中度、共同前提、記憶體稀釋 capex 的第二次佐證）不受影響，仍然有效。依 append-only 原則，原報告留在原地，索引會標示為已取代。

## 待辦與缺口

**第一優先（決定上面所有判斷的可信度）：**

- **歷史遠期本益比分位**——十一檔中九檔只有 trailing 或完全沒有。這直接決定 bear 錨是查得值還是推論值，也決定上面「七戰全負是洞見還是偏誤」能否回答。取得途徑：Koyfin／GuruFocus／Bloomberg 的 forward PE band；台股用 Goodinfo 本益比河流圖或券商看盤軟體
- **三檔台股（3324、6442、3008）的技術面與歷史倍數**——台股報價頁為 JS 動態渲染，WebFetch 取不到。這是**可補的缺口，非本質性不可得**，需換取得途徑

**其次：**

- MSFT、INTU、6442 的街上目標價未取得，差異化評估缺三檔
- MSFT bull 的 31x 口徑（trailing 或 forward）待確認
- 3008 的 CPO 貢獻自下而上估算——以 bear 的 17x（2026-04/06 市場實際付過的價，即題材發酵前）為參照，現價 36.4x 與之的差額即市場對 CPO 的隱含定價，**約每股 3,700 元**。把那個數字算出來，比爭論 36.4x 貴不貴有意義得多
- MU 的中週期正常化 EPS 需自下而上估算，用以驗證市場隱含的 58 美元
- `coverage.yaml` 的 `memory` 因子註記應由「一個部位的兩種寫法」改為「同向但不等深」
