## 一、⚠ 解開阻塞的東西在我建檔前六天就已存在，而我沒找到

建檔時我寫下：

> **「這是資料最完整、卻是錨最少的一檔 —— 資料夠而尺不夠。」**

本輪解開它的，是公司在 **2026-09-02** 法說會上給出的多年期路徑：

| | AI 半導體營收 |
|---|---|
| FY2026 | 約 **$58B**（公司當期預期） |
| **FY2027 目標** | **$115B**（約當倍增） |
| **FY2028 目標** | **$230B**（再倍增，為 FY2026 的 **4.0 倍**） |

⚠ 並且：**兩年供給皆稱已鎖定**；管理層明言**實際需求已超過 FY2027 的 $115B 目標，
限制條件是晶圓與先進封裝產能，不是訂單**；
⚠⚠ **另稱 FY2028 EPS 將超過 $30。**

```
現價 357.90 ÷ 公司指引的 FY2028 EPS 30 = 11.93x
```

### ⚠ 為什麼我建檔時沒有這些

**我讀了 8-K 的附件 99.1（財報新聞稿），而這三個數字在法說會上，不在 8-K 裡。**

> **這與 3030 建檔時漏掉一則八天前的報導是同一類流程失誤，但成因不同：**
> 那次是**入口單一**（只看報價頁的 news sidebar）；
> **這次是「讀了一手文件就以為讀完了」—— 8-K 的新聞稿與法說會是兩個不同的來源。**

## 二、⚠ 但這些數字全是二手轉述，而本輪自己撞到了證據

$115B／$230B／FY2028 EPS >$30 **全部來自媒體對法說會的轉述**
（Motley Fool、CNBC、Yahoo、Bloomingbit、TechTimes、AIC——多來源一致），
**一手逐字稿未讀，而我讀過的 8-K 不含它們。**

### 而同一類來源，本輪在一個我查得到的數字上弄錯了口徑

| | |
|---|---|
| CMoney 2026-09-07 | 「調整後 **EBITDA** 指引 約66%」 |
| **8-K 原文（一手）** | 「Non-GAAP **operating income** guidance of approximately 66 percent」 |

> ⚠⚠ **EBITDA ≠ 營業利益。**
>
> **在無法逐字核對的數字上，不得因為它是好消息就升信心。**

**這是本輪信心維持「低」的第一個、也是最具體的理由。**
已把「取得法說會逐字稿或簡報並核對這三個數字」列為 `changes_if` 的最高優先。

## 三、forward PE 的基準年爭議解開了，並帶出一個實質發現

建檔時我記下一個未解的矛盾：頁面 forward PE **20.68**（隱含 EPS 17.31），
而 49 位分析師的 FY2026 共識是 **11.64**（隱含 30.75x），**差 48.7%**。

**本輪由三個獨立推導收斂：**

| 推導 | FY2027 EPS |
|---|---|
| ① 頁面 forward PE 20.68 反推 | **17.31** |
| ② 由指引建構（AI 115B＋非AI 59.2B＝174.2B）｜營益率 58% / 62% / 66% | **17.30 / 18.49 / 19.69** |
| ③ 幾何內插 FY2026 共識 11.64 與 FY2028 指引 30 | **18.69** |

> **三法收斂於 17–20，頁面隱含值落在其中 → 20.68 幾可確定是 FY2027。**

### ⚠ 而②同時給出一個實質發現

**頁面隱含的 17.31 對應約 58% 的營益率——較公司 Q4 指引的 66% 低 8pp。**

> **市場已經把利潤率壓縮算進去了。** 這一點直接進了 base 的 `multiple_basis`。

⚠⚠ **但 17.31 由現價推導，絕不可用作情境 EPS——用它就是循環論證。**
情境的 EPS 一律由指引建構。

## 四、基準年由 FY2026 滾至 FY2027（依步驟 3）

三個理由：FY2026 結束於 2026-11-01，**只剩七週且殘餘度僅 0.25**；
**市場已經滾了**（第三節的三法確認）；公司已給出多年期指引。

> ⚠ **目標價的跳動主要來自換基準年，不是重評價。**

**代價**：FY2027 共識分布在付費牆後，**錨寬度只能沿用 FY2026 的 3.35%**——
而那描述的是**一個只剩一季且已被指引的年度**，**不可移作 FY2027 的確定性**。

**三基準年輸出**：FY2026E **11.64**（49 位共識）→ FY2027 建構 **18.47** → FY2028 **>30**（公司指引）。
⚠ **本檔是覆蓋清單中唯一三個年度都有數字的標的。**

### 倍數的邊界取自街上目標所隱含的倍數（對 base EPS 18.47）

| 街上目標 | 隱含倍數 |
|---|---|
| 最低 215.88 | **11.7x** |
| 均值 533.41 | **28.9x** |
| 最高 715 | **38.7x** |

- **bear 14x 高於 11.7x**——本情境假設的是「指引未達成」，**不是「公司出事」**
- **bull 30x 低於 38.7x**——**不把「營收超標」與「倍數到最樂觀」兩個樂觀相乘**，
  那是本倉庫反覆記錄的自欺形態

### 5b. 循環性檢查——通過

```
base 406 對現價 357.90 = +13.5%
base 22x 對「現價 ÷ base EPS」19.38x = +13.5%
```

> **不是抄現價。**

### ⚠ base 22x 的檢驗方式是換算到 FY2028

```
base 406 ÷ 公司指引的 FY2028 EPS 30 = 13.5x
```

> **即使 base 成立，對公司自己指引的 FY2028 盈餘仍只有 13.5 倍。這個倍數不算積極。**

### ⚠ 族群序位本輪完全無法執行，這是實質限制不是省略

三家的 forward PE **分屬不同會計年度**（AVGO FY2027、NVDA 依其 state 記載可能已滾至 FY2028、
MRVL 年結亦不同）。

> **口徑未對齊前不可比較。故 base 的 22x 不含任何族群序位調整。**

## 七、訊號：中性（維持）／信心 低（維持）

**⚠ 上檔 +17.4%，且現價僅 11.93x 公司指引的 FY2028 EPS，而評級仍是中性。**

**不給偏多**：`confirm_trigger` 是「收盤站回 50DMA 383.66 之上並連三個交易日維持」，
**現況 357.90 距此 +7.2%，不成立**；價格**同時在 50DMA 與 200DMA 之下，下方無均線支撐**。

> ⚠ **依 SKILL.md：升級為偏多需右側技術確認，目標價再高都不跳過。**
> **本輪同時出現「上檔 +17.4%」與「11.93x FY2028 指引 EPS」，而技術面仍未確認——
> 這是那條規則最該生效的組合。**

**不給偏空**：加權目標價高於現價；Q4 有明確指引且方向向上；
49 位分析師 **37 強力買進／0 賣出**；50DMA 仍高於 200DMA。

### 信心維持低——五個理由

1. ⚠⚠ **多年期指引全為二手轉述**，而同一類來源本輪已證實會弄錯口徑（第二節）
2. **客戶集中度仍無一手來源**——而它正是 bear 情境的觸發機制
3. **自身歷史 forward PE 區間仍未取得**，錨 A 仍是空的
4. ⚠ **族群序位確認無法執行**（會計年度不對齊）
5. **FY2027 共識分布在付費牆後**

### ⚠ 一個必須誠實記下的不對稱

> **本輪關掉的缺口（成長持續期的錨、forward PE 基準年）都靠二手來源；
> 仍然打不開的缺口（客戶集中度、自身歷史倍數、族群口徑）都需要一手文件或付費資料。**
>
> **證據品質的分布是傾斜的。**

## 八、falsifier
