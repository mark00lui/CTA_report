# 8046 全量重估 —— 用單一券商的預估當了共識

## 0. 病因：不是版本過期，是來源層級

篩檢 24 檔台股時，本檔被判為「base EPS 綁具名年度 ＋ 指名共識來源」的**三檔乾淨檔之一**
（另兩檔是 2308 與 3037）。細讀後發現判錯了 —— 它綁的年度是對的（FY2027），但綁的不是共識。

證據在 bull 的 `multiple_basis` 裡，state 自己寫的：

> ⚠ EPS 35.2 為推導值：以 FactSet 2026（17.08）對**美系外資** 2026（11.52）的 1.48 倍比例，
> 外推**該外資的 2027（23.78）**至 FactSet 口徑，得 35.2。**非直接取得的估值，列入 gaps**

**亦即 base 的 23.78 是單一美系外資的 FY2027 估計，而 bull 的 35.2 是把它乘 1.48 倍外推。**

| | 值 | 來源 |
|---|---|---|
| state 的 base FY2027 EPS | **23.78** | 單一美系外資 |
| state 的 bull FY2027 EPS | **35.2** | 上者 × 1.48（口徑換算） |
| **FactSet FY2027 共識中位數** | **42.34** | 16 位分析師，2026-08-28 |
| FactSet FY2027 共識最高 | 65.83 | 同上 |
| FactSet FY2027 共識最低 | 21.66 | 同上 |

**共識中位數比 state 採用值高 78.0%，而連 state 的 bull（35.2）都低於共識中位數 16.9%。**

⚠⚠⚠ **這違反 `references/forward-estimates.md` §7 的明文規定：「不得用單一券商的預估當共識。
它是全距的一個端點。」** 而它被寫進了權重 0.5 的 base。

### ⚠⚠ 但 state 當時已經算出那個數字不合理 —— 它缺的只是一條通道

`key_variables` 的「市場共識的分散度」裡，state 自己寫：

> ⚠ **2027（基準年）仍無分布**（Pro 付費牆），故三情境的 2027 EPS 仍為單一來源。
> 可做的交叉檢查：2025 實績 3.01 → 2026 共識均 18.21（+505%）→ 2027 採用值 23.78（+30.6%）；
> ⚠ **但若 2026 落在共識上緣 21.80，則 2027 的 23.78 僅隱含 +9.1% 成長** ——
> **2026 的實績落點會直接決定 2027 的成長**

**它正確地診斷出「一家在漲價上行段、稼動率還有空間的載板廠不會只成長 9%」，
並且明寫了付費牆是障礙。它沒錯在判斷，錯在不知道鉅亨網的 Factset 速報新聞免費給這張表。**

**→ 這是 `forward-estimates.md` 這份方法文件存在的理由的最乾淨實例：
問題不在分析能力，在通道。**

## 1. 基期重建：每股淨值必須跟著獲利路徑一起動

本檔的主錨是 **PB**（錨 A 的 PE 口徑失效 —— 分母趨零，三年區間跨 93 倍），
所以 EPS 的修正不是直接改目標價，而是**先改每股淨值**。

### 1.1 實際值（取代 state 的推導值）

| | 值 | 來源 |
|---|---|---|
| 每股淨值 2026-06-30 | **76.24** | 資產負債表（實際） |
| state 記的「現況 PB 16.13x」隱含的每股淨值 | 68.8 | **偏低 9.7%** |
| 以實際值重算的現況 PB（價格 1,080） | **14.16x** | 1,080 ÷ 76.24 |

⚠ **state 的 PB 16.13x 是用偏低的每股淨值算的。** 歷史序列：
FY2021 62.64／FY2022 83.14／FY2023 74.14／FY2024 70.34／FY2025 71.38／**2026Q2 76.24**。

### 1.2 2027 年底每股淨值的推導

| 步驟 | 值 | 備註 |
|---|---|---|
| 2026-06-30 實際 | 76.24 | |
| ＋ H2'26 EPS | **+10.67** | ＝ FY2026 共識 17.08 − H1'26 約 6.41 |
| − 2026 除息 | −2.00 | DPS TTM 2.00；台股除息多在 Q3，故在 6/30 之後 |
| **＝ 2026 年底** | **84.91** | |
| ＋ FY2027 EPS | 依情境 | 21.66／42.34／65.83 → 本檔取 15.00／42.34／65.83（見 §2） |
| − 2027 除息 | −6.83 | ＝ FY2026 盈餘 17.08 × 40% |

⚠ **兩個假設必須標示**：
1. **H1'26 EPS 約 6.41 是推論** —— 由 TTM 8.51 扣除推估的 H2'25（約 2.1）而得。
   逐季 EPS 未取得。**若 H1'26 實際更高，則 H2'26 更低，2026 年底每股淨值下修。**
2. **2027 的配發率 40% 是假設** —— 歷史區間由每股淨值變動反推為 **32–66%**
   （FY2022→23 約 60%、FY2023→24 約 46%、FY2024→25 約 66%）。
   **取 40% 偏低，對目標價是偏保守的方向。**

**→ 2027 年底每股淨值：93.08（bear）／120.42（base）／143.91（bull）。
state 的單一值 97.9 在新的 base 下低 18.9%。**

⚠⚠ **而每股淨值是存量，它的離散度（1.55 倍）遠小於 EPS 的離散度（4.39 倍）——
PB 框架天然地抑制了盈餘預估的分歧。這是它在循環股上的優點，也是下面全距討論的關鍵。**

## 2. 三情境

| 情境 | p | FY2027 EPS | 來源 | 2027 年底每股淨值 | PB | 目標價 | 隱含 PE | FY2027 ROE | 相對現價 |
|---|---|---|---|---|---|---|---|---|---|
| **bear** | 0.25 | **15.00** | ⚠ **刻意低於共識下緣** | 93.08 | 4.0x | **372** | 24.8x | 16.9% | −65.6% |
| **base** | 0.50 | **42.34** | FactSet 共識**中位數** | 120.42 | 6.0x | **723** | 17.1x | 41.2% | −33.1% |
| **bull** | 0.25 | **65.83** | FactSet 共識**最高** | 143.91 | 14.0x | **2,015** | 30.6x | 57.5% | +86.6% |

**算術加權 ＝ 0.25×372 ＋ 0.50×723 ＋ 0.25×2,015 ＝ 958**（前值 759，**+26.2%**）
**相對錨定價 1,080 為 −11.3%**（前值相對同一價為 −29.7%）

### 2.1 ⚠⚠ bear 刻意低於共識下緣，而這需要一個具名機制

**bear 的 15.00 比 FactSet 的 FY2027 共識下緣 21.66 低 30.7%。**

依 2026-09-11 在 2308 那一輪訂下的做法，三情境的 EPS 應取共識分布的低／中位／高。
**本檔刻意違反下緣那一格，理由是具名的**：state 的 bear 敘事是
「ABF 漲價循環在 2027 前結束、亞洲同業恢復接 BT 訂單使供給收縮逆轉」——
**而賣方共識不模型化循環破裂，它只模型化漲價幅度不如預期。**

⚠ **規則因此要補一條**：**共識分布是情境全距的「下限」，不是上限。
超出它只能靠一個共識明確沒有模型化的機制，而且要寫出超出了多少。**

### 2.2 ⚠⚠⚠ 另一個理由：共識分布的下緣本身被汙染了

| FY2026 的共識分布 | 低 | 中位／平均 | 高 | 錨寬度（高−低）÷低 |
|---|---|---|---|---|
| stockanalysis（11 位，2026-09-08） | **16.07** | 均 18.21 | **21.80** | **35.7%** |
| FactSet（16 位，2026-08-28） | **8.56** | 中位 17.08／均 16.64 | **21.80** | **154.7%** |

⚠⚠⚠ **高值完全相同（21.80），低值差 1.9 倍 —— 錨寬度的量測值因此差 4.3 倍，完全取決於供應商。**

**而 FactSet 的低值 8.56 本身不可能成立**：TTM（至 2026-06）EPS 已是 8.51、
H1'26 約 6.41 —— **8.56 等於假設 H2'26 只有 2.15，而上半年是 6.41。那是一個未更新的舊估計。**

**→ 通則：共識分布的下緣特別容易被未更新的估計汙染，而在共識快速上修的標的上，
汙染幅度會很大（本檔 FY2026 共識中位數在 2026 年內自 2.0 升到 17.08）。
引用下緣前要做一次合理性檢查：它與已實現的期間數字是否矛盾。**

**這同時削弱了把共識下緣當 bear 的做法 —— 本檔取 15.00 反而比取被汙染的 21.66 更有意義。**

### 2.3 ⚠⚠⚠ PB 6.0x 現在被它自己隱含的 ROE 驗證了

state 的 `check` 是 Gordon 合理 PB ＝（ROE−g）／（r−g），參數 ROE 30%、r 11%、g 5% → **4.17x**，
而 base 取 6.0x，**原本需要這個辯護**：「高於 ROE 30% 反推的 4.17x，等於認列漲價使 ROE 超越常態」。

| ROE | Gordon 隱含 PB | |
|---|---|---|
| 30%（舊假設） | 4.17x | base 取 6.0x → **需要辯護** |
| **41.2%**（新 base 的 FY2027 ROE） | **6.03x** | base 取 6.0x → **誤差 0.5%，不需要辯護** |

⚠⚠ **主錨（PB 6.0x）與正交檢查器（Gordon）現在獨立地收斂到同一個值。**
**而這不是我調參數調出來的 —— Gordon 的三個參數（ROE 除外）一個字沒動，
只有 ROE 因為 EPS 來源修正而自 24.3% 變為 41.2%。**

⚠ **但必須記下 r ＝ 11% 仍然沒有可觀測錨**（台幣無風險利率取不到，見 §5）。
**Gordon 的收斂是在一個未錨定的 r 上成立的 —— 若 r 更高，Gordon 值下降，6.0x 就又變成需要辯護。**
**敏感度：r 12% → 5.17x；r 13% → 4.53x。→ 這個驗證的強度取決於一個缺口。**

### 2.4 ⚠⚠ 全距 5.42 倍 —— 算術加權是弱摘要統計量

| | 值 | 相對現價 |
|---|---|---|
| 算術加權 | **958** | **−11.3%** |
| 幾何加權 | **791** | **−26.7%** |
| 兩者差 | **21.1%** | |

**全距 ＝ 2,015 ÷ 372 ＝ 5.42 倍，遠超「≥3 倍則算術平均嚴重偏移」的門檻。**

⚠ **而這個全距是真實的，不是建構假象**：
- **EPS 本身跨 4.39 倍**（15.00 → 65.83），而其中 3.04 倍來自共識自己的分布（21.66 → 65.83）；
- **自身三年 PB 實際區間是 1.40–16.39x**，本情境用的 4.0–14.0x 還在其內；
- 每股淨值的離散只有 1.55 倍 —— **PB 框架已經把 EPS 的分歧抑制過一次了，剩下的是真分歧。**

⚠⚠⚠ **→ 本檔的加權目標價是一個弱摘要統計量。有訊息量的輸出是情境階梯本身，
而最該讀的一行是「base 723 相對現價 −33.1%」：即使用共識中位數，本檔在 PB 框架下仍偏貴三成。**

### 2.5 ⚠ 隱含 PE 階梯不是單調的

| 情境 | 隱含 PE |
|---|---|
| bear | **24.8x** |
| base | **17.1x** |
| bull | 30.6x |

**bear 的隱含 PE 高於 base —— 因為分子（每股淨值）是存量、跌得比分母（EPS）慢。**

⚠ **這是 PB 錨定在循環股上的結構性特徵，不是錯誤**，但它有一個後果：
**PB 框架與 PE 框架會對「哪一個情境最便宜」給出不同答案。**
state 在 base 的 `multiple_basis` 裡已經寫過這個張力（「PE 觀點會說這太保守，PB 觀點會說這已經很寬鬆」）——
**本輪補上的是：那個張力在 bear 那一格會反向，而舊的單調階梯（24.2／24.7／42.5）掩蓋了它。**

## 3. 同業序位 —— 三個成員、同一供應商、逐年標註

**這是本輪第二個實質成果**：ABF 載板三家首次在**同一供應商、同一年度**上可比。

| | 現價（2026-09-11） | FY2026 中位 | FY2027 中位 | FY2028 中位 | **FY2027 PE** | FY2028 PE | beta | 位數 |
|---|---|---|---|---|---|---|---|---|
| **8046 南電** | 1,080 | 17.08 | **42.34** | 82.62 | **25.51x** | 13.07x | 2.08 | 16 |
| 3037 欣興 | 977 | 18.96 | 34.24 | 59.74 | 28.53x | 16.35x | 2.34 | 20 |
| 3189 景碩 | 822 | 10.57 | 21.42 | 41.12 | **38.38x** | 19.99x | 1.84 | 14 |
| **族群中位** | | | | | **28.53x** | 16.35x | | |

### ⚠⚠ 序位與 state 記的完全相同，但水準低 26–33%

| | state 記的（資料商 forward PE，**年度不明**） | 逐年標註後的 FY2027 | 差異 |
|---|---|---|---|
| 8046 | 33.73 | **25.51** | −24.4% |
| 3037 | 38.71 | 28.53 | −26.3% |
| 3189 | 43.03 | 38.38 | −10.8% |

**→ 序位（8046 < 3037 < 3189）是對的，水準全錯。**
**而序位對、水準錯，正是「同業序位能驗證相對、驗證不了絕對」那條規則（8299 訂）的反面實例：
這次是序位可用而水準不可用，所以能做的是相對定位，不能做的是用族群水準反推目標價。**

### ⚠⚠⚠ 而一個意外：市場的倍數序位是 ABF 曝險度的反序

| | ABF／IC 載板營收占比 | FY2027 PE | FY26→27 EPS 成長 | FY27→28 成長 |
|---|---|---|---|---|
| **8046** | **近 90%**（最純） | **25.51x**（最便宜） | **+147.9%**（最陡） | +95.1% |
| 3037 | 52% | 28.53x | +80.6% | +74.5% |
| 3189 | （未取得） | 38.38x（最貴） | +102.6% | +92.0% |

**市場在 FY2027 基礎上給最純的 ABF 曝險最低的倍數** ——
而 3037 事先寫定的第一個排序指標正是「ABF 載板營收占比」。

⚠⚠ **合理的解釋是市場按成長斜率排而不按純度排**：8046 的 FY26→27 成長最陡（+147.9%），
所以它在「已經長完的那一年」上的倍數最低。**FY2028 的序位相同（13.07／16.35／19.99），
支持這個解釋。**

⚠⚠⚠ **但不得因此事後換掉排序指標 —— 那是 valuation.md 明文禁止的自欺。**
**正確處置：記錄「事先寫定的排序指標未能解釋市場的倍數序位」，並立一個可驗證的替代假說
（倍數序位由 FY+1→FY+2 的成長斜率決定），在下一輪檢驗它。**

## 6. 否證點的調整

**第三條「2026 全年 EPS 低於 11.52 元」的門檻已失去約束力 ——** state 於 2026-09-08 已記下
這一點（當時新下緣 16.07 > 11.52）。本輪處置：

| | 舊 | 新 | 理由 |
|---|---|---|---|
| 第三條門檻 | FY2026 EPS < **11.52** | FY2026 EPS < **14.00** | 14.00 要求 H2'26 ≤ 7.59 對 H1'26 的約 6.41，**即漲價上行段中 H2 幾乎不成長**，有約束力；而 11.52 要求 H2'26 ≤ 5.11，**低於已實現的 H1**，幾乎不可能觸發 |

**新增第五條（直接測 base 的輸入）：**

> **FactSet 的 FY2027 共識中位數自 42.34 下修逾 15%（即低於 36.00）**，check_by 2027-03-31

⚠ **為什麼要立一條測共識而不是測公司的否證點**：**base 的 723 完全建立在共識中位數 42.34 上，
而本輪已證明這個輸入曾經錯了 78%。** 既有四條測的是毛利率、月營收、FY2026 EPS 與稼動率 ——
**沒有一條測「我採用的那個預估有沒有被市場自己推翻」。**
⚠ 限制要寫明：**它測的是共識不是公司。** 共識下修可能是對的也可能是錯的 ——
觸發時要做的是重新檢查基期，不是直接下修目標價。
