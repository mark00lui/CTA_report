# 6531 全量重估（同日第二次）—— 共識輸給自建估計的第一個實例

## 0. 本輪與今日稍早那一輪的分工

今日稍早的 `2026-09-11-6531-revaluation.md` 建立了三情境與加權目標價 805，
主要發現是 PB 與 ROE 的反向關係（本檔 PB 12.78 最高而隱含 ROE 21.6% 最低）。
**本輪不重做那件事，而是處理它沒有碰的三件：**

| | 稍早那一輪 | 本輪 |
|---|---|---|
| `valuation_base_year` | 仍是 `None`（但 key_assumption 實際用 FY2027） | **設為 2027** |
| 遠期共識 | **一條都沒查過** | 兩條通道都查了，結果見 §1 |
| 同業倍數的年度歸屬 | 快照有 PE／PB 但**無年度標註** | **確認 19.79 是 trailing，見 §2** |

**三個目標價（280／770／1,400）與加權 805 一個字未動 —— 本輪沒有任何新的估值判斷。**
**變的是錨定價（1,045 → 988）與對現有數字的理解。**

⚠ **並記一個發現的不一致**：state 的 `cta.price` 是 **1,045**（updated 2026-09-10），
而稍早那份報告的 `tp_delta` 寫「相對 2026-09-10 收盤 **1,030**」，
sources 另記 wantgoo 2026-09-11 10:35 盤中 **984.00**。
**三個數字互不相同，而 state 取了最高的那一個。** 本輪統一到 2026-09-11 收盤 **988.00**。

## 1. ⚠⚠⚠ 共識輸給自建估計 —— 而分析師人數是判準

### 1.1 兩條通道的結果

| 通道 | 結果 |
|---|---|
| 鉅亨 Factset 速報（EPS 型） | **零筆** —— 本檔無 FactSet 覆蓋（只有營收速報與盤中速報） |
| stockanalysis `/forecast/` | **FY2026 有：營收 101.1 億（+78.36%）／EPS 17.90（+131.26%）—— 但只有 2 位分析師**；**FY2027／FY2028 付費牆** |

**→ 基準年（FY2027）的共識兩條通道都取不到。而 FY2026 的共識只有 2 位分析師。**

### 1.2 而那個 2 位分析師的共識被月營收否證了

依 `forward-estimates.md` §6：把共識的年營收換算成「月營收需要達到什麼水準」。

| | 值 |
|---|---|
| 1–8 月累計營收（實際） | **65.99 億元**（YoY +109.13%） |
| FY2026 共識營收 | 101.1 億元 |
| **→ 9–12 月需要** | 35.11 億元 → **月均 8.78 億元** |
| **而 7 月／8 月實際** | **11.04 億／10.31 億 → 月均 10.68 億元** |
| **共識隱含的後四月變動** | **−17.8%** |

⚠⚠⚠ **共識要求 9–12 月的月營收比 7–8 月衰退 17.8%，而 8 月的年增率還有 +150.82%。**

**若 9–12 月僅維持 7–8 月的月均水準（不假設任何進一步成長）：**

| | 值 | 對共識 |
|---|---|---|
| FY2026 營收 | 65.99 ＋ 42.70 ＝ **108.69 億元** | **+7.5%** |
| FY2026 淨利（以 state 的淨利率 28.8%） | 31.30 億元 | |
| **FY2026 EPS**（÷ 1.6315 億股） | **19.19** | **+7.2%** |

**→ 而 state 自建的「FY2026E 約 19」與這個結果吻合。**
**亦即：2 位分析師的共識輸給了用月營收自建的估計。**

### 1.3 ⚠⚠⚠ 而這與 8046 的結論方向相反 —— 判準是分析師人數

| 檔 | 分析師數 | 共識 FY2027 | state 自建 | 誰對 |
|---|---|---|---|---|
| **8046 南電** | **16 位** | 42.34 | 23.78（單一美系外資） | **共識贏，自建低 43.8%** |
| **6531 愛普** | **2 位** | 17.90（FY2026） | 19.19（月營收推算） | **自建贏，共識低 6.7%** |

⚠⚠⚠ **這是一條該回填的規則：「用共識還是用自建估計」不是原則問題，是分析師人數的函數。**

**而台股有一個美股沒有的仲裁者：月營收。**
**它是法定的、每月公告的、與共識完全獨立的觀測值 ——
所以「共識對不對」這件事在台股是可以每月裁決的，不必等財報。**

⚠ **本檔的分析師人數（2–3 位）低到什麼程度**：對照 2308 的 23 位、3037 的 20 位、
8046 的 16 位、3008 的 17 位、華邦電的 10 位。**本檔是本輪處理過的標的中覆蓋最薄的。**
**→ 建議門檻：分析師數 < 5 時，共識僅供對照，以月營收自建的估計為主。**

## 2. ⚠⚠⚠ base 的 35x：內插區間的上界與下界不同口徑

state 對 base 的 35x 寫得非常誠實：

> ⚠⚠⚠ 本項是三情境裡唯一沒有第一性依據的部分，必須誠實標示。
> **上下界都是觀測值：同業最高 19.79（華邦電）與現價隱含 46.8 倍（1,030 ÷ 22.0）；
> 但 35 這個點是區間內插，不是估值。**

**本輪發現：那兩個「觀測值」不是同一個口徑。**

| | 值 | 口徑 |
|---|---|---|
| 「同業最高 19.79（華邦電）」 | 19.79 | **trailing PE**（快照 as-of 2026-09-10 13:30，無年度標註） |
| 「現價隱含 46.8 倍」 | 1,030 ÷ 22.0 | **forward，且是 FY2027**（base 的 EPS 就是 FY2027 的 22.0） |

**華邦電 2344 的年度標註倍數（現價 171.50，2026-09-11）：**

| 年度 | 共識 EPS（FactSet 中位，10 位） | 倍數 |
|---|---|---|
| TTM | 9.05 | **18.95x** ← 與快照的 19.79 同口徑 |
| FY2026 | 25.37 | **6.76x** |
| **FY2027** | **50.05** | **3.43x** |
| FY2028 | 48.73 | 3.52x |

⚠⚠⚠ **同年度（FY2027）的華邦電是 3.43x，而不是 19.79x —— 差 5.8 倍。**
**內插區間的上界是 trailing、下界是 forward，所以「35 落在區間內」這句話沒有內容。**

⚠⚠ **但不要因此把 35x 往 3.43x 的方向調** —— 華邦電**有自有晶圓廠、做商品記憶體、
且正處於循環峰**（FactSet 的 FY2028 中位 48.73 **低於** FY2027 的 50.05，
亦即共識明確預期記憶體循環在 FY2027 見頂）。
**「峰值盈餘配低倍數」正是循環股的典型定價，而本檔是無廠設計、淨利率 28.8%、
處於 IoTRAM 放量段 —— 兩者的 3.43x 與 35x 不該被放在同一把尺上比。**

**→ 結論：錨 B 不成立。**
唯一有年度標註的同業（華邦電）結構上不可比，另兩家（晶豪科 3006、鈺創 5351）仍無年度標註的倍數。
**依 `valuation.md`「同業序位需至少三個可用成員」—— 可用成員為 0。**

⚠ **而這比 state 原本的說法更嚴重**：state 說「35 是區間內插，不是估值」；
**本輪說的是「那個區間根本不存在」。**
**處置：35x 維持不動（沒有更好的錨），但在 `multiple_basis` 把「區間內插」降級為
「無錨，僅以現價隱含值折價 22.1% 表述」，並把 conviction 的「低」再加一個具名理由。**

## 4. thesis 的爭點被月營收回答了一半

**thesis：「爭點是 Q2 EPS 季增僅 1% 是暫歇還是 IoTRAM 這一段的頂」**

| | 值 |
|---|---|
| Q2 月均營收 | 7.88 億元 |
| **Q3 前兩月月均（7 月 11.04／8 月 10.31）** | **10.68 億元** |
| **QoQ** | **+35.5%** |
| 8 月 YoY | **+150.82%** |
| 7 月 YoY | +145% |

⚠⚠⚠ **營收面強烈指向「暫歇」而非「頂」。**

⚠ **但 thesis 只被回答了一半**：**EPS 的另一半是利潤率，而 Q3 財報未出。**
**若 Q3 的淨利率低於 Q2 的 28.8%（例如新產品爬坡期的良率壓力），
營收 +35.5% 未必等於 EPS +35.5%。**
**→ thesis 維持不變，但爭點的一半已有答案，另一半的驗收時點是 Q3 財報（約 2026-11）。**

⚠ **而這也是 §1 那條規則的實例**：**月營收不只能否證共識，也能回答 thesis 的爭點 ——
它的頻率是季報的 3 倍，所以「等財報」這件事在台股常常是不必要的。**

## 7. 回填 references 的新增項

1. ⚠⚠⚠ **「用共識還是用自建估計」是分析師人數的函數，不是原則問題。**
   **實測：8046（16 位）的共識贏，state 自建值低 43.8%；本檔（2 位）的自建贏，共識低 6.7%。**
   **建議門檻：分析師數 < 5 時，共識僅供對照，以月營收自建的估計為主；
   而引用任何共識時必須同時寫出分析師人數（§3 已要求，本例說明它為什麼重要）。**
2. ⚠⚠⚠ **月營收不只能否證共識，也能回答 thesis 的爭點。**
   **本檔實測：thesis 問「Q2 是暫歇還是頂」，而 Q3 前兩月月均對 Q2 月均 +35.5%、
   8 月 YoY +150.82% —— 營收面已答，不必等財報。**
   **→ 台股的月營收是季報頻率的 3 倍，所以「等財報」常常是不必要的；
   但它只答營收那一半，利潤率那一半仍要等。**
3. ⚠⚠⚠ **內插區間的兩個端點必須同口徑，否則「落在區間內」這句話沒有內容。**
   **本檔實測：上界「同業最高 19.79」是 trailing PE，下界「現價隱含 46.8x」是 FY2027 forward；
   同年度的華邦電實際是 3.43x，與 19.79 差 5.8 倍。**
   **→ 這是 §5「倍數與 EPS 必須同年度」的一個變形：
   不只標的自己的倍數與 EPS 要同年度，用來界定範圍的端點彼此也要同年度。**
4. ⚠⚠ **同業的「峰值盈餘配低倍數」不可直接套用到非循環的標的上。**
   **華邦電的 FY2027 3.43x 之所以低，是因為 FactSet 的 FY2028 中位（48.73）低於 FY2027（50.05）
   —— 共識明確預期循環在 FY2027 見頂。而本檔是無廠設計、淨利率 28.8%、處於放量段。**
   **→ 比較倍數前要先看同業自己的 FY+1→FY+2 成長方向：若為負，它的低倍數是循環訊號不是估值訊號。**
