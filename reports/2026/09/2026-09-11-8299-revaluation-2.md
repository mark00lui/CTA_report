# 8299 全量重估（同日第二次）—— declared primary method 不是產生這個 base 的那個方法

## 0. 本輪要解的是 state 自己標記的「最弱的一環」

稍早那一輪在 `base.key_assumption` 寫：

> ⚠⚠⚠ 本項是本次重估最弱的一環 —— **我沒有獨立證據判斷峰值的多少是結構性的**

而 `valuation_frame.methods.primary` 寫：

> **中週期正常化 EPS × 正常倍數**（時間軸）。
> ⚠⚠ **這不是我選的，是 valuation-map 對這個方法的註記直接規定的：「循環股必用」。**
> ⚠ **前置條件是「中週期 EPS」，本輪未取得（列 gaps）。**

**本輪做兩件事：取得 FactSet 的三年共識，並用 state 自己的歷史序列把中週期 EPS 算出來。**
**三個目標價一個字未動 —— 變的是我們現在知道 base 站在哪裡。**

## 1. ⚠⚠⚠ 三個框架相差 3 倍，而 declared primary method 給的是最低的那一個

| 框架 | FY2027 EPS | × base 倍數 8x | 相對現價 2,085 |
|---|---|---|---|
| **中週期正常化**（五年平均，含 FY2026 共識中位） | **103.23** | **826** | **−60.4%** |
| **state 自建**（現行 base） | **200.0** | **1,600** | **−23.3%** |
| **FactSet FY2027 共識中位** | **308.27** | **2,466** | **+18.3%** |

**全距 2.99 倍。**

### 中週期正常化的計算（closed gap）

state 自己的 `bear.key_assumption` 已經記了歷史序列：

| 年度 | EPS |
|---|---|
| FY2022 | 27.50 |
| FY2023 | 18.48 |
| FY2024 | 39.07 |
| FY2025 | 42.12 |
| FY2026（共識中位） | **388.99** |

| 正常化口徑 | 值 |
|---|---|
| 四年（FY2022–FY2025）平均 | **31.79** |
| 四年中位 | 33.28 |
| **五年（含 FY2026）平均** | **103.23** |
| 五年中位 | 39.07 |

⚠⚠⚠ **而 state 的 base 200 是五年平均的 1.94 倍、四年平均的 6.29 倍。**
**→ declared primary method（中週期正常化）不是產生這個 base 的那個方法。**

### ⚠⚠ 這比 3037 的「兩個錨方向相反」更嚴重，因為這裡有一個宣告的主錨

3037 的情況是：錨 B 與 Gordon 對 base 的方向相反，而 state 沒有宣告哪一個是主錨。
**本檔的情況是：state 明確宣告主錨是「中週期正常化 EPS × 正常倍數」，
並且註明「這不是我選的，是 valuation-map 直接規定的：循環股必用」——
而它執行出來的 base 高於那個方法 94%。**

⚠ **`valuation.md` 的原文更嚴格**：循環股「不可用峰值 EPS × 峰值倍數。
若採市場慣用的『峰值 EPS × 低倍數』，**必須並列『中週期正常化 EPS × 正常倍數』的版本，
讓兩者差距被看見**」。
**→ 本輪把那個並列做出來了，而差距是 1.94 倍。**

### 為什麼本輪仍不把 base 改成 103.23

**因為 103.23 也不是一個乾淨的中週期值，而 state 給了一個具名的理由不採用它：**

> 仍高於 FY2024（39.07）與 FY2025（42.12），**反映 AI 帶動的企業級需求有一部分是結構性的**

**四年平均 31.79 完全不含 AI／企業級的結構性轉變；五年平均 103.23 則被單一年度
（FY2026 的 388.99）主導 —— 它是「一個谷底期 ＋ 一個極端峰值」的平均，不是一個週期的平均。**

⚠⚠⚠ **→ 處置與 3037 相同：base 維持不動，但把衝突與幅度寫清楚，並把 conviction 壓住。**
**而本檔要多寫一句：「AI 帶動的企業級需求有一部分是結構性的」這個說法現在是 base 唯一的
load-bearing 假設，而它至今沒有被量化 —— 沒有數字說明那個「一部分」是多少。**

⚠ **並記一個必須避免的辯護**：五年平均 103.23 與共識中位 308.27 的中點是 205.8，
而 state 的 200 距它只有 2.8%。**但「碰巧落在中間」不是辯護理由 ——
那正是同日 3081 那一輪剛記下的教訓。**

## 3. 全距與加權 —— 本輪最極端的一檔

| | 值 | 相對現價 2,085 |
|---|---|---|
| 算術加權 | **1,640** | **−21.3%** |
| 幾何加權 | **1,289** | **−38.2%** |
| 兩者差 | **27.2%** | |

**全距 3,000 ÷ 360 ＝ 8.33 倍 —— 本輪七檔中最寬**
（3081 6.30×、8046 5.42×、6531 5.00×、3008 4.72×、3037 4.79×、2308 2.48×）。
**算術／幾何落差 27.2% 也是本輪最大**（3081 22.3%、8046 21.1%）。

⚠ **而本檔的全距來源**：**EPS 全距 5.00 倍（60 → 300）、倍數全距僅 1.67 倍（6x → 10x）
—— 寬度幾乎全部來自 EPS。**
**這與 3008 正好相反**（該檔 EPS 全距 1.26 倍、倍數 3.75 倍，寬度來自「CPO 成不成功」的二元事件）。

⚠ **但 8.33 倍的全距使「加權目標價」這個單一數字的資訊量很低 ——
最該讀的是 base 1,600（−23.3%）與共識隱含的 2,466（+18.3%）之間的那個決定。**

## 6. 回填 references 的新增項

1. ⚠⚠⚠ **要檢查「declared primary method 是不是產生這個 base 的那個方法」。**
   **本檔實測：`methods.primary` 宣告「中週期正常化 EPS × 正常倍數（循環股必用）」，
   而執行出來的 base 高於該方法 94%。**
   **宣告與執行脫節，比「沒有宣告主錨」更難察覺 ——
   因為 `valuation_frame` 看起來是完整的。**
   **→ 建議檢查方式：把 declared primary method 的輸入實際算出來，與 base 並列。
   本檔的輸入（中週期 EPS）本來就列在 gaps 裡，而沒有人去算它。**
2. ⚠⚠⚠ **共識本身可以逐年遞減，而那是循環股的正常形態 —— 不要誤讀為「共識看空」。**
   **本檔實測：FY2026 388.99 → FY2027 308.27 → FY2028 243.73（約 −21%／年），
   而共識目標價仍是 2,740（相對現價 +31.4%）。**
   **→ 共識的 EPS 方向與共識的目標價方向可以相反，因為倍數會擴張。引用時要分開講。**
3. ⚠⚠ **「模型比街上快幾年」是一個可量化的診斷，而它兩個方向都會發生。**
   **實測三例：3008 的基準年停在 FY2026（慢一年）；3081 的 FY2027 base ≈ 街上的 FY2028（快一年，上行方向）；
   本檔的 FY2027 base 200 低於街上的 FY2028 243.73（快約一年半，下行方向）。**
   **→ 診斷方法：把自建的 base 與街上的 FY+1／FY+2／FY+3 逐一比對，看它落在哪一年。**
4. ⚠⚠ **「bull 低於街上的基準情境」是一個該系統性檢查的形態。**
   **本輪已累積三個實例：2308（舊 bull 的成長假設低於公司自己的營收指引）、
   8046（舊 bull 35.2 低於共識中位 42.34 達 16.9%）、本檔（bull 300 ≈ 共識中位 308.27）。**
   **→ 檢查方式：bull 的 EPS 必須高於共識中位；若不是，bull 那一格沒有存在意義。**
5. ⚠ **全距的來源要分解成 EPS 與倍數兩段，而它決定加權平均有沒有意義。**
   **本檔：EPS 全距 5.00 倍、倍數 1.67 倍 → 寬度來自 EPS（循環深度，連續型）→ 加權有意義。**
   **3008：EPS 1.26 倍、倍數 3.75 倍 → 寬度來自倍數（CPO 二元事件）→ 加權無意義。**
   **→ 同樣是「全距超過 3 倍」，處置完全不同。**
